Common beginner errors

Understand the cause. Find a fix.

Python explains what failed, why it happened, and the line to check. Wrong answers can also be logic errors: the code runs, but the result is not what you intended.

SyntaxError · punctuation

Cause: Python can't parse the line, often because a quote or colon is missing.

Try: if score > 5: needs a colon; print("Hi") needs matching quotes.

IndentationError · spaces

Cause: Lines inside a function, loop, or condition aren't indented consistently.

Try: indent the body by four spaces, for example print("Hello").

NameError · spelling

Cause: A variable name is misspelled or has not been created yet.

Try: define it first, such as score = 10, and use the exact same spelling.

TypeError · value types

Cause: An operation received the wrong kind of value, such as adding text and a number.

Try: convert the number with str(age), or check that a list contains numbers before calling sum().

Logic error · wrong result

Cause: The code runs, but a condition or calculation does something different than intended.

Try: check operators: even numbers use % 2 == 0; highest-first sorting uses reverse=True.
