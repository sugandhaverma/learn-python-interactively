The learning path

Small ideas. Big possibilities.

Go in order, or jump to the topic you need. Each card includes a tiny example to try.

01

Say hello

print() displays a message. Text needs quote marks.

print("Hello, world!")
02

Store a value

A variable is a name for a value. Use = to assign it.

name = "Mina"
print(name)
03

Make a choice

if runs code only when a condition is true. Indent its body.

age = 12
if age >= 10:
    print("Ready!")
04

Repeat a task

A for loop repeats once for every item in a sequence.

for number in range(3):
    print(number)
05

Keep a list

Lists hold multiple values. Square brackets make a list.

colors = ["blue", "gold"]
print(colors[0])
06

Make a function

A function is a reusable recipe. Define it with def.

def greet():
    print("Hi!")

greet()

A few useful habits

Python likes things tidy.

✓ Do

  • Use four spaces to indent code inside an if, loop, or function.
  • Choose clear names like favorite_color.
  • Use matching quote marks: "hello" or 'hello'.
  • Test one small change at a time.

× Don't

  • Use spaces in variable names: write first_name, not first name.
  • Forget the colon at the end of if, for, and def lines.
  • Mix tabs and spaces for indentation.
  • Assume = and == mean the same thing.
i

Remember: Python is case-sensitive. name and Name are different names.

Errors are clues

Oops! What went wrong?

Everyone gets errors. Read the message, find the line, and check these usual suspects.

SyntaxError Missing quote or colon +

Python can't understand the code's shape. Check that strings have matching quotes and statements like if end with a colon.

# Not quite
print("Hello)

# Fixed
print("Hello")
IndentationError Code is not lined up +

The body of an if, loop, or function must be indented consistently, usually by four spaces.

if True:
    print("Indented inside the if")
NameError A name is not defined +

Check for a typo or make sure you assigned the variable before using it. Names are case-sensitive.

favorite = "mango"
print(favorite)  # same spelling
TypeError Values don't work together +

Some operations need matching types. Convert a number to text before joining it with other text.

age = 10
print("Age: " + str(age))
IndexError List position is out of range +

List positions start at 0. A list with two items has positions 0 and 1.

pets = ["cat", "dog"]
print(pets[0])  # cat
