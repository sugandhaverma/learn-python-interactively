When code trips

Errors are clues, not grades.

A syntax or indentation error points to code Python cannot run. A logic error means the code ran but used the wrong order. Ask: does the newest item leave first, or the oldest?

IndexError · empty stack

Calling pop() on an empty list has no item to remove. Check the stack before popping.

Logic error · mixed-up order

Stacks use append() and pop(). A list-based queue removes the first item with pop(0).
