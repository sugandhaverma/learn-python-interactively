When code trips

Errors are clues, not grades.

A syntax or indentation error stops Python and points to a line. A logic error means the code ran but found the wrong index or count. Check index boundaries and update the search range every round.

IndexError · off-by-one

The first list index is 0. The last valid index is len(items) - 1, not len(items).

Logic error · search stuck

Binary search must change low or high each time. Otherwise the loop may never reach the answer.
