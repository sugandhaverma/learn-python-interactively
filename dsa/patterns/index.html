Pattern hints

One row at a time.

Use an outer loop to choose the row. Use the row number to decide how many spaces, stars, or digits to make. Check the named line when the shape looks different.

SyntaxError · missing colon

Loop headers need a colon: for row in range(4):. Indent the line that prints each row.

IndentationError · row not inside loop

The row-building and printing lines need four spaces inside the outer loop. Press Tab in the editor to add them.

Logic error · wrong shape

If rows are too short or repeat, check how the row number controls the output. A centered pyramid needs 2 * row + 1 stars.
