When code trips

Errors are clues, not grades.

Check loop boundaries and compare the correct pair of values. A logic error means the program ran, but one or more swaps were skipped or happened in the wrong direction.

IndexError · neighbor missing

When comparing numbers[i] and numbers[i + 1], stop before the last index.

Logic error · wrong order

For ascending order, swap when left is greater. For descending order, swap when left is smaller.
