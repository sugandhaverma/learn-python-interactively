When code trips

Errors are clues, not grades.

A syntax or indentation error stops Python and points to a line. A logic error means the code ran but the answer was unexpected. Check your loop bounds, starting values, and comparisons—then try again.

IndexError · wrong position

List indexes start at 0 and end at len(items) - 1. In a reverse loop, include index 0.

Logic error · missed item

Check whether your loop visits every item, and whether your starting value is sensible (like 0 for a sum).
