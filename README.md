# Python, one step at a time

A friendly, interactive Python learning path. Start at `index.html` and choose **Basic Python**, **Intermediate Python**, or **Data Structures & Algorithms**.

## Run locally

Open `index.html` in a browser. The code playground downloads Pyodide the first time you run code, so an internet connection is needed. The playground runs Python in your browser and does not support `input()`.

## Folders

- `basic-python/` — beginner syntax, examples, common errors, an interactive code runner, and a quick check.
- `intermediate-python/` — ten interactive coding challenges covering common intermediate Python patterns and line-by-line error guidance.
- `dsa/` — a topic-based DSA course with separate interactive lessons for arrays, searching, sorting, stacks & queues, and loop-based pattern problems.
